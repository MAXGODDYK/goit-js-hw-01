# JavaScript — домашнє завдання №1

Три функції для обчислення вартості замовлення дроїдів, вартості доставки та ширини елемента.

- [Репозиторій](https://github.com/MAXGODDYK/goit-js-hw-01)
- [Жива сторінка](https://maxgoddyk.github.io/goit-js-hw-01/)

## Завдання

1. `js/task-1.js` — `makeTransaction(quantity, pricePerDroid)`.
2. `js/task-2.js` — `getShippingMessage(country, price, deliveryFee)`.
3. `js/task-3.js` — `getElementWidth(content, padding, border)`.

## Перевірка

Відкрий `index.html` або живу сторінку, натисни F12 і перейди на вкладку Console.
У консолі виводяться результати дев'яти перевірочних викликів з умов завдань.

Код відформатовано Prettier. Повторна перевірка форматування:

```sh
npx prettier@3.9.0 --check .
```
